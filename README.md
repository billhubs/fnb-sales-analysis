📝 Project: End-to-End F&B Sales Performance Analytics
(A Business Case Simulation based on Mie Gacoan’s Operational Model)

🛡️ Project Overview
Proyek ini merupakan simulasi analisis data end-to-end yang dirancang untuk menjawab tantangan nyata di industri F&B. Dataset dibangun secara sintetis menggunakan Python untuk mencerminkan dinamika transaksi, struktur menu, dan margin operasional dari bisnis retail makanan berskala besar.

1. Key Performance Indicators (KPI) - Simulated Q1 2024
Total GMV (Gross Merchandise Value): Rp 50,607,000.

Average Gross Margin: 57.95% (Mencerminkan efisiensi biaya bahan baku/COGS).

Top Performing City: Malang memimpin dengan Revenue Mie sebesar Rp 15.2jt.

Product Performance: Mie Setan teridentifikasi sebagai produk dengan kontribusi margin tertinggi.

2. Strategic Business Insights
Beverage Attach Rate Issue: Di area Malang, ditemukan rasio penjualan Mie vs Minuman sebesar 10:1. Ini menunjukkan adanya lost opportunity pada kategori produk bermargin tinggi.

Actionable Recommendation: Implementasi strategi "Dynamic Bundling" (Mie + Es Genderuwo) untuk meningkatkan Average Order Value (AOV) dan mengoptimalkan utilitas inventaris minuman di jam-jam sibuk (peak hours).

3. Technical Implementation & Data Engineering
ETL Pipeline: Proses ekstraksi dan transformasi data mentah menggunakan Python (Pandas) untuk penanganan nilai hilang (data cleaning) dan normalisasi tipe data.

Query Optimization Logic: Simulasi penarikan data menggunakan SQL CTEs (Common Table Expressions) untuk memastikan efisiensi pemrosesan data transaksi dalam jumlah besar (Query Cost Optimization).

Visual Reporting: Dashboard interaktif dibangun di Looker Studio dengan fitur cross-filtering dan date range control untuk mendukung pengambilan keputusan berbasis data bagi tim operasional.
